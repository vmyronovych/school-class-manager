# Мокапи

Інтерактивний мокап (Ant Design 5, три екрани): https://claude.ai/artifact/Mir1TQ4aNCZreU333AeEvX

Сам мокап намальовано до рішень від 24.09.2026 і в ньому застаріло: логіни `4a.ivanenko` (тепер `ivanenko.petro.2011`), кнопки класів замість `Select`, кнопка «Перевести». Де мокап і цей файл розходяться — чинний цей файл.

Макет спільний для всіх екранів: `Layout` → темний `Sider` 220 px (`#001529`, `Menu` з п'ятьма пунктами, внизу статус Pi) + білий `Header` 56 px (`Breadcrumb` ліворуч, сповіщення й `Avatar` користувача праворуч) + `Content` на `#f5f5f5`. Токени — стандартні antd (`colorPrimary #1677ff`, radius 6/8, шрифтовий стек системи).

## Учні `/students`

| Зона | Компоненти antd | Дані |
| --- | --- | --- |
| Заголовок | Title + «46 облікових записів · 2 класи · 3 вимкнених»; кнопки «Імпорт CSV», «Картки логінів», primary «+ Учень» | `/classes`, `/students` |
| Фільтри | `Select` класу з пошуком (Усі / 3-А / 4-А / … — у школі 15–20 класів, `Radio.Group` не влазить) + `Radio.Button` «Вчителі», `Input.Search`, лічильник «Вибрано: N» | `/classes` |
| Таблиця | `Table` з `rowSelection` (checkbox), колонки: Логін (mono), Прізвище ім'я (посилання), Клас, Статус (`Tag`: success «Активний», warning «Заблокований», default «Не входив», error «Вимкнений») з фільтром, Останній вхід, Папка; `Pagination` | `/students?class=&q=` |
| Картка учня | `Card` з `title` (ім'я) + `Tag` статусу; `Descriptions` (логін, поточний клас і попередні, останній вхід і ПК, папка, пароль змінено); primary «Скинути пароль»; сітка 2×2 «Файли», «Розблокувати», «Картка PDF», `danger` «Вимкнути» (переведення між класами немає — `docs/plan.md`, «Класи»); список «Знімки папки» з «Відновити…» | `/students/{login}`, `/students/{login}/snapshots` |

Діалоги: «+ Учень» — `Modal` + `Form` (клас `Select`, прізвище, ім'я, рік народження) → результат з логіном/паролем і «Картка PDF». «Імпорт CSV» — `Modal` + `Steps` (файл → превʼю `Table` з помилками → прогрес `Progress` через SSE → звіт). Скидання пароля — `Modal` з паролем, «Копіювати», «Друк картки».

## Сервер `/server` (Admin) і Налаштування `/settings` — у мокапі не деталізовані

Сервер: `Descriptions` (версії, uptime, диски + SMART), `Table` знімків з «Видалити старіші за…», `Card` бекапів (останні 10, «Запустити»), `Select` юніта + `<pre>` з логом (SSE), `Card` «Оновлення» з доступною версією і `Popconfirm` «Оновити». Налаштування: `Form` (генератор паролів, ролі), `Descriptions` read-only (домен, шляхи), «Про застосунок».
