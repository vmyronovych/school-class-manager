# School Class Manager

Шкільна панель для керування учнівськими обліковими записами, перегляду робіт і перевірки стану комп’ютерів. Учень входить у Windows під своїм доменним іменем із будь-якого ПК класу. Диск H:, документи та робочий стіл зберігаються на сервері. Учитель відкриває панель у браузері.

**Для першого розгортання** візьміть архів `scm-0.2.0-amd64.tar.gz` та відповідний файл `.sha256`. Архів містить панель, інсталятор агента MSI, серверні сценарії та інструкції. На шкільних комп’ютерах збирати проєкт або встановлювати .NET не потрібно.

1. [Установіть сервер і підключіть перший ПК](docs/install.md).
2. [Перевірте резервну копію та опануйте оновлення](docs/operations.md).

Пакет призначений для нового домену Samba в Ubuntu Server 24.04 на шкільному Windows-хості з Hyper-V. Агент підтримує учнівські комп’ютери з процесором Intel або AMD та 64-бітною Windows. Він надсилає стан ПК після запуску служби й кожні п’ять хвилин. Для щоденної роботи вчителю достатньо членства в групі вчителів.

## Збірка з вихідного коду

На Ubuntu 24.04 встановіть Git, Node.js 24 з npm, SDK з `global.json` та пакети `wixl` і `msitools`. Виконайте ці команди в корені репозиторію.

```sh
sudo apt-get install wixl msitools
dotnet test -c Release
python3 tests/test_folder_redirection.py
bash deploy/package.sh amd64
npm --prefix web test -- --run
```

Архів і контрольна сума з’являться в `out/`. Версію задає `Directory.Build.props`. Підвищуйте її для кожного нового пакета. У GitHub Actions перевірка Windows встановлює MSI, оновлює попередню службу зі збереженими параметрами та перевіряє звіт після її перезапуску. Стан перевірки дивіться для конкретної версії коду.
