# Робота над School Class Manager

Почніть із README.md. Інструкції для адміністратора містяться в docs/install.md та docs/operations.md. Сервер працює в Ubuntu 24.04, клієнт — служба Windows x64. Сервер і клієнт використовують .NET 10.

Зберігайте межі доступу. Панель працює від імені scm. Операції з доменом проходять через scm-directory. Скрипт перевіряє SID і групу користувача. Передавайте паролі через стандартний ввід. Не записуйте паролі, стан живого домену або учнівські файли в Git.

Перевіряйте зміни на окремому домені. Розрізняйте перевірку в Ubuntu, тест служби на Windows і застосування групової політики на шкільному ПК.
